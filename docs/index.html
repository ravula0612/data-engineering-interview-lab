Study plan

Four-week roadmap

Use each week to practice a skill and explain a trade-off aloud.

  1. Week 1

    Write and explain queries

    Practice joins, windows, and deterministic deduplication. End with the SQL & Python round.

  2. Week 2

    Diagnose a slow Spark job

    Use execution plans and task metrics to distinguish skew, spill, and poor file layout.

  3. Week 3

    Build for replay and recovery

    Reason through checkpoints, late data, and idempotent writes. End with the Spark & Databricks round.

  4. Week 4

    Design and defend a pipeline

    State the grain, freshness target, failure modes, and backfill policy. Take the senior design mock.
